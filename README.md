# Peter Stegall — CS-499 ePortfolio

A starter GitHub Pages website inspired by the organization of the example CS-499 portfolio.

## Files
- `index.html` — page content and navigation
- `styles.css` — colors, layout, typography, and responsive styling

## Customize before publishing
1. Replace the placeholder text in `index.html` with your own self-assessment, course examples, artifact descriptions, and narratives.
2. Add links to your original and enhanced code repositories and code review video.
3. Review all content for personal information you do not want publicly visible.

## Publish with GitHub Pages
1. Create a repository named `YOUR-USERNAME.github.io` for a personal site, replacing `YOUR-USERNAME` with your GitHub username.
2. Upload `index.html`, `styles.css`, and `README.md` to the repository's root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.
5. Wait for the site to publish and use the URL shown in the Pages settings.

GitHub's official instructions: https://docs.github.com/en/pages/quickstart
